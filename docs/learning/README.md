# Learning Notes

PocketNode is an academic learning project. Every completed task must leave a
learning note in this directory.

Learning notes explain what practical skills were used, what was learned, what
was difficult, which validation proved the work, and how future tasks should
reuse the lesson.

## Required Workflow

For every completed task:

1. Create or update `docs/learning/YYYY-MM-DD-<task-slug>.md` from
   `docs/templates/learning-note.md`.
2. Add the task and skills to `docs/learning/skill-index.md`.
3. Link the learning note from the story, validation report, trace notes, or
   final response.

Examples of skills to track:

- WASM and browser-native PWA architecture.
- Responsive web app behavior for mobile browsers.
- SQLite in the browser, including WASM, OPFS, and fallback storage.
- CRDT and HLC merge behavior.
- Browser peer pairing and LAN-adjacent sync constraints.
- WebCrypto and Google Drive E2EE backup.
- Go backend API design.
- Consent-first AI request handling.
- Local AI benchmarking in WebGPU/WASM environments.
- Privacy-preserving telemetry.
